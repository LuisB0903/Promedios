## ✨ Descripción

**Promedios** es una aplicación sencilla para calcular el promedio de calificaciones de estudiantes. Permite calcular el promedio automáticamente y mostrar si el estudiante aprobó o no.

## 🚀 Características

- Ingreso fácil de calificaciones
- Cálculo automático del promedio
- Indicación de aprobación o reprobación
- Interfaz intuitiva

## 🛠️ Instalación

1. Clona el repositorio:
    ```bash
    git clone https://github.com/tuusuario/Promedios.git
    cd Promedios
    ```

## 🖥️ Uso

Ejecuta el programa con:
```bash
g++ main.c
```
Sigue las instrucciones en pantalla para ingresar las calificaciones.

## 📄 Ejemplo

```
Ingrese la cantidad de materias: 3
Nota 1: 8
Nota 2: 7
Nota 3: 9
El promedio es: 8.0
¡Aprobado!
```
